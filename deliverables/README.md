# Pericles handoff artifacts

These generated artifacts correspond to source commit `b25f483` (the following commit adds only these deliverables). They are included in git by explicit request despite the normal ignore rule for Roblox place files.

- `civitas-place.rbxlx` — main procedural city and experimental shuttle place.
- `civitas-rail-test.rbxlx` — separate isolated rail prototype.

See `docs/reports/pericles-app-report.md` and `PLAYTEST.md` for scope, verification and outstanding runtime risks. Neither place has been tested in Roblox Studio. Rebuild both with `bash tools/verify.sh` after installing the pinned tools.
